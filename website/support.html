Parley Support

Parley is a private, bring-your-own-key AI chat app for iOS.

Contact

Email ruobin.wang.us@gmail.com for help, bug reports, feature requests, or to report a problematic AI response. Reports can also be sent directly from the app: touch and hold any assistant reply and choose Report response.

Do I need an API key?

Not on an Apple Intelligence–capable device — Parley defaults to Apple's on-device model, which is free, offline, and needs no account. To use a cloud model (OpenAI, Anthropic, Google, DeepSeek, xAI, OpenRouter, or a custom endpoint), open Settings → Provider, pick one, and paste an API key from that provider's website. You are billed by the provider directly; Parley adds no markup and has no subscription.

Why does a provider return an error?

  • Check the API key is valid and has credit remaining with the provider.
  • Check the selected model name is one your key can access — use Settings → Model → fetch models to list what your key offers.
  • For Ollama or custom endpoints, confirm the server URL is reachable from your device.

How does web search work?

Web search uses your own Brave Search API key (free tier available at brave.com/search/api). Arm the globe button for a message and the answer is grounded in current results with source links.

Where is my data?

Conversations stay on your device; keys stay in the iOS Keychain. See the privacy policy for the full picture.
